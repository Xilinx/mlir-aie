99/// \brief Routes flows in a device by lowering them to stream-switch
100/// configurations.
101///
102/// Overall flow:
103/// 1. Rewrite all flows in the device into switchboxes + shim-mux.
104/// 2. Run multiple passes of the rewrite pattern, rewriting stream-switch
105/// configurations to routes.
106/// 3. Rewrite flows to stream-switches using 'weights' from the analysis pass.
107/// 4. Check that a region is legal.
108/// 5. Rewrite stream-switches (within a bounding box) back to flows.
