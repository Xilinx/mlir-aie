Detailed Description

What one op in a loop body does to a channel queue.

The two lowering paths spell pushes and awaits with different ops, so the fixed point below takes the classification from its caller and keeps the FIFO rule to itself.

Free is a read-only check, not a hardware event: a dma_free_task returns a buffer descriptor id to the compiler's pool without touching the channel, so it neither pushes nor retires anything here. It asks whether task's own push – the one a later pop could still be waiting behind – has already been proven complete.
