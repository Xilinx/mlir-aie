The runtime sequence is left out, so a device ranks the same whatever sequence drives it.

◆ rank()

DenseMap< Operation *, unsigned > StructuralGraph::rank ( ) const

Rank the nodes by their features and then, a round at a time until no class splits, by the ranks of the nodes they link to.

Neither op order nor symbol names play a part, so a permuted or renamed design ranks alike, and nodes left with one rank cannot be told apart.
