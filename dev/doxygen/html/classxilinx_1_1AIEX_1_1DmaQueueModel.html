Detailed Description

Tracks, per DMA channel, the pushes not yet known to have completed along one execution path.

The sequence analysis below joins control-flow paths.

static void xilinx::AIEX::DmaQueueModel::awaitToken ( ChannelState &  q)
inlinestatic

Retire what a task-completion-token await proves has drained.

The sync pops whichever token the channel produces first – the oldest outstanding token-issuing push, not necessarily the task the await names – and in-order execution means everything queued ahead of it has drained too. With no token-issuing push queued, nothing can be retired.

Record that a queue-space poll has guaranteed room.
