Lookup register by tile-relative offset and module name.

Used by the transaction-binary locmap to decorate each transaction word with its semantic register name. Module names are the JSON keys in aie_registers_aie2.json: "core", "memory", "memory_tile", "shim". Returns nullptr if no register matches.
