Places groups first fit: with callerOrder, in order on each one's candidates, then in canonical order (canonicalFirstFit); without, in canonical order only.

On a miss: exact bipartite matching when every group takes one count, else exact packing, which leaves the first-fit placement standing if no packing exists or the search runs out of kPackBudget steps. The SA places in canonical order only, so it fits only where allocation's own-order-first pass fits too.

The lock groups owners lock owners of a pool of depth objects take, by count.

With semaphore locks each owner is a segment taking a pair, one lock counting free objects and one full ones; otherwise the one owner is the pool, taking a binary lock per object.
