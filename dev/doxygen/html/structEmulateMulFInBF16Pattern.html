Detailed Description

Pattern to emulate an f32 multiply with bf16 inputs.

The product of two bf16 values fits in f32 except at the ends of the exponent range, so only the inputs are rounded: r = arith.mulf a, b : vector<16xf32> becomes r = arith.mulf (extf (truncf a)), (extf (truncf b)) : vector<16xf32>
