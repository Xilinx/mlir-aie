Detailed Description

The packet ids a device has already spoken for.

Every switchbox rule on a stream matches on the id, so two flows sharing one is a routing hazard, and whoever hands out ids reads this first. It counts every holder, whatever stage the design is at: an aie.packet_flow, the pinned header of an aie.route or of an aie.objectfifo not yet split, and an aie.trace.packet with an id.
