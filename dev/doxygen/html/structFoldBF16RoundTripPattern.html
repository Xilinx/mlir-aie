Detailed Description

Pattern to drop bf16 -> f32 -> bf16 round trips.

Arith used to fold these but no longer does: widening a signaling NaN quiets it, so the original bit pattern cannot be recovered. This pass has always made that trade anyway – smartTruncF32ToBF16 collapses the same pair on sight – so fold here to keep the pipeline's pre-existing behavior rather than leaving the round trips for the backend.
