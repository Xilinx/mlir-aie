Detailed Description

The BD ids tiles' own programs hold before objectFIFOs take theirs: the chains DMA programs start by index, on their channels, and each id a runtime sequence pins (AIEX::forEachRuntimePinnedBdId), once per tile, on the lowest channel up to its own reaching it (aie-reserve-runtime-bd-ids keeps static BDs off those).
