Detailed Description

The mem tiles a mem tile pool's buffers go to: aie-objectfifo-allocate places them by this search, and the SA placer runs it on each placement it weighs.

A tile's use is its layout by assignSequentialBufferAddresses. Each buffer in turn goes home when it fits there, else to a neighbour home shares memory with, least used first; when one fits nowhere, earlier choices are revisited, latest first, until kRetries alternatives have been tried.

bool xilinx::AIE::MemTileSpillSearch::place ( llvm::ArrayRef< Buffer > buffers)
inline

Places buffers in order on top of what the tiles hold.

On success each buffer's tile is in chosen; otherwise failed is the buffer that fit nowhere with the most buffers left after it, and unplacedBytes the bytes of it and those. Buffers whose tiles reach no tile in common place independently, so each such component is searched on its own, with its own kRetries.
