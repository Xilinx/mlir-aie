Discardable attribute set by --aie-objectfifo-lower-cores on the rank-0 memref.allocas that hold a core's objects of an objectFifo in rotation order.

The AIEObjectFifoUnroll pass promotes them to SSA on each core where every object then folds to its buffer. Otherwise they stay in memory, so that LLVM's SROA carries only the buffer pointer around the loop rather than the whole memref descriptor.
