    About these numbers

    Every metric is smaller-is-better. A change counts once it passes the metric's threshold, the same one the pull-request report uses. Cycles and object size are the numbers the checks gate on; host time moves with the machine, so it only counts past three times its run-to-run spread.

    Only turbo-mode runs are compared: the nightly measures in turbo, and older runs in other modes are hidden unless you ask for them on Trends. A dashed line on a chart marks a change of Peano, host, runtime or driver between nights.
