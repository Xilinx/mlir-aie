CT   = Compute Tile (AIE core + L1 memory, 64KB = 4x16KB banks)
MemT = Memory Tile  (L2 shared scratchpad, 512KB)
Shim = Shim Tile    (DMA engine for L3 <-> NPU data transfer)

Memory Hierarchy:
  L3 (DDR)  <--Shim DMA-->  L2 (MemTile)  <--Stream-->  L1 (Compute Tile)
  Host-side                  Shared buffer               Per-core local memory
  GB scale                   512KB/tile                  64KB/tile

Data Flow (typical):
  Host DDR --> Shim(R0) --> MemTile(R1) --> ComputeTile(R2-R5) --> MemTile(R1) --> Shim(R0) --> Host DDR

Tile Coordinates: Tile(column, row)
  Shim tiles:    Tile(col, 0)
  MemTiles:      Tile(col, 1)
  Compute tiles: Tile(col, 2) through Tile(col, 5)

IRON Placement Sentinels:
  AnyShimTile    -> auto-assign row 0
  AnyMemTile     -> auto-assign row 1
  AnyComputeTile -> auto-assign rows 2-5 (default for Workers)
